# FitAI — Интеллектуальная база знаний по спорту и тренировкам

Веб-приложение (SPA) с персональным ИИ-тренером и структурированным каталогом упражнений. Проект спроектирован с учётом RAG-архитектуры (поиск релевантных упражнений в базе знаний перед формированием ответа) и готов к интеграции с локальными языковыми моделями (Ollama / LM Studio) и будущим бэкендом.

---

## Основной функционал (Frontend MVP)

- **Главная страница:**
  - Быстрая строка запроса с ротацией подсказок и мгновенным переходом в диалог с ассистентом.
  - Сводная статистика по базе знаний и быстрая навигация по разделам.
- **Чат с ИИ-тренером:**
  - Стартовый экран со сценариями популярных запросов.
  - Локальный RAG-поиск: подбор релевантных упражнений по целевым мышцам, инвентарю и целям с прикреплением интерактивных карточек-источников под ответом.
  - Рендеринг ответов в формате Markdown, копирование текста в один клик и очистка истории диалога.
  - Многострочный ввод (`Enter` — отправка сообщения, `Ctrl + Enter` или `Shift + Enter` — перенос на новую строку).
- **База упражнений:**
  - Живой поиск по названию, мышечным группам и инвентарю.
  - Фильтрация по категориям (*Грудь, Спина, Ноги, Плечи и руки, Кор и кардио*).
  - Детальная карточка упражнения с пошаговой техникой выполнения, списком частых ошибок и кнопкой быстрого разбора с ИИ-тренером.

## Технологический стек

- **React** + **Vite** — сборка и компонентная архитектура
- **React Router DOM** — клиентская маршрутизация с плавными переходами между разделами
- **Lucide React** — минималистичные векторные иконки
- **React Markdown** — форматирование ответов ИИ-ассистента
- **CSS Variables** — единая тёмная дизайн-система (`#0E0F12` + лаймовый акцент `#84CC16`)

## Запуск проекта локально

1. Перейдите в директорию фронтенда и установите зависимости:
   ```bash
   cd frontend
   npm install
   ```

2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере адрес `http://localhost:5173`.

## Подключение локальной LLM (Ollama / LM Studio)

В файле `frontend/src/api/mockApi.js` предусмотрен объект конфигурации `LLM_CONFIG` для переключения с демо-режима на локальный сервер, совместимый с OpenAI API:

```js
export const LLM_CONFIG = {
  mode: 'ollama', // 'mock' | 'ollama' | 'lmstudio'
  endpoint: 'http://localhost:11434/v1/chat/completions', // для LM Studio: http://localhost:1234/v1/chat/completions
  model: 'qwen2.5:7b',
};
```

> **Примечание:** при прямом обращении из браузера к локальному порту необходимо разрешить CORS в настройках LM Studio или запустить Ollama с переменной окружения `OLLAMA_ORIGINS="*"`.
